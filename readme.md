## 🏗️ Production work

<details open>
<summary><b>🏦 MCB Islamic Bank — Enterprise Intranet</b> · <i>500+ employees · LDAP · RBAC</i></summary>
<br/>

**Problem:** Approval workflows at a national bank ran on paper and took days to move between HR, IT and Operations.
**Solution:** A role-based routing system integrated with the bank's enterprise LDAP directory.
**Impact:** Approval chains that took days are now fully digital, trackable and auditable for 500+ employees.

</details>

<details open>
<summary><b>🔄 IFL — Enterprise Workflow Automation</b> · <i>8 roles · AD SSO · Oracle HRMS</i></summary>
<br/>

**Problem:** IT onboarding and offboarding required manual coordination across many teams and approvers.
**Solution:** Multi-stage automation across 8 roles, with approvals done straight from **Outlook actionable-card emails**, Active Directory SSO and Oracle HRMS sync.
**Impact:** Configurable Primary/Secondary approver routing with **2-day automatic fallback** — requests never stall on an absent approver.

</details>

<details open>
<summary><b>💳 TheOlivePod — Donation Platform</b> · <i>Stripe · GoCardless · SumUp · AWS</i></summary>
<br/>

**Problem:** Donations arrived through three different payment providers with no single source of truth.
**Solution:** A MERN financial engine processing **Stripe, GoCardless and SumUp** together, with secure, idempotent webhook pipelines.
**Impact:** **100% accurate transaction reconciliation** and near-zero downtime since launch, deployed on AWS with Docker, NGINX and automated CI/CD.

</details>

<details open>
<summary><b>🍔 FoodFactory — POS Ecosystem</b> · <i>Electron · NestJS · Supabase · Next.js</i></summary>
<br/>

**Problem:** Restaurant branches lost sales whenever the internet went down.
**Solution:** An **offline-first Electron desktop POS** with background sync, backed by a containerized NestJS/Supabase API and a Next.js admin portal.
**Impact:** Branches keep selling through outages; data **reconciles automatically** on reconnect.

</details>
